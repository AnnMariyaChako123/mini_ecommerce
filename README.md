Mini E-commerce Website

Project Description
A basic e-commerce website developed using Python and Django. This project demonstrates the implementation of essential e-commerce functionalities, including product management, shopping cart, checkout, and order management.
Features

*Product, category, and brand management

*Product search, filtering, and pagination
*Product images, pricing, discounts, and stock management
*Shopping cart and quantity management
*Checkout and delivery address management
*Order creation, order history, and order status management
*Razorpay payment integration
*Payment verification and webhook handling
*Customer accounts and authentication
*Wishlist, product reviews, and ratings
*Email notifications and background tasks using Celery and Redis
*API development and frontend-backend integration
*Django Admin management and sales reporting
*Form validation, security checks, and regression testing

Purpose

This project was developed to gain practical experience in Django web development and understand the core concepts of building a basic e-commerce website.
